# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v54.0.0/ before writing any code.

Pinned to SDK 54 (not the latest) on purpose: Apple's App Store review has been
lagging Expo's release cadence, so the public Expo Go client only supports
whatever SDK Apple has most recently approved — SDK 57 required `eas go` (a
paid Apple Developer account) to run on a real iPhone at all. Before bumping
this SDK again, confirm the target SDK is already live in the App Store
version of Expo Go, not just published by Expo.
